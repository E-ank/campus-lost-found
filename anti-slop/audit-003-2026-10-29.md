# antislop audit-003: PWA LOST & FOUND (2026-10-29)

Mode antislop: **after** (pilihan pengguna di sesi ini).

- **Design Read:** `DESIGN.md` (arah tercatat, lint bersih): aplikasi layanan
  kampus, bahasa "utilitas biru kerajaan", dial **ENERGY 2 / RHYTHM 2 / MOTION 1**.
- **Cakupan:** manifest PWA, service worker, halaman offline, kartu pemasangan,
  metadata layout, ikon, dan header `/sw.js`. Fitur PWA ditambahkan ke aplikasi
  yang sudah ada; audit ini memeriksa permukaan baru dan dampaknya ke Beranda.
- **Metode:** inspeksi kode, `next build`, `tsc --noEmit`, CDP Edge
  (installability, UI, mobile, keyboard, offline), dan `contrast-check.py`.
- **Verifikasi offline kuat:** server produksi dihentikan dan cache HTTP browser
  dibersihkan sebelum reload. Shell tetap tampil dari Cache Storage, bukan dari
  cache HTTP.

---

## Temuan dan status

### HIGH: Hard Gate

**1. Kontras subtitle pita offline (R-25)**
- Sebelum: `#dbeafe` di atas `#2563eb` = **4.24:1** pada teks 10px. GAGAL ambang
  normal 4.5:1.
- Perbaikan: `#eff6ff` di atas `#2563eb` = **4.75:1**. PASS.
- Bukti: `contrast-check.py` mengembalikan PASS untuk normal dan large text.

**2. Focus indicator tombol pasang dan tutup (R-32)**
- Sebelum: kedua tombol tidak punya ring fokus kustom yang konsisten di atas
  permukaan biru/putih.
- Perbaikan: `focus-visible:ring-2` + `ring-offset-2` pada tombol pasang dan
  tombol tutup; tombol tutup diberi `aria-label="Tutup ajakan pasang aplikasi"`.
- Bukti: uji keyboard CDP mencapai "Pasang aplikasi" dan "Tutup ajakan pasang
  aplikasi"; kedua tombol menampilkan ring; tidak ada console error.

**3. Cache offline belum menyimpan aset build (R-27, C-4)**
- Sebelum: precache hanya 5 URL (`/`, `/offline.html`, manifest, 2 ikon).
  Shell offline masih tampil karena cache HTTP browser, bukan karena Cache
  Storage. Jika cache HTTP dibersihkan, aset bisa hilang.
- Perbaikan: `sw.js` v3 membaca HTML `/` yang sudah di-cache, mengekstrak
  `/_next/static/...`, dan menyimpannya saat install.
- Bukti: cache berisi 15 entri (5 shell + 10 aset build). Setelah
  `Network.clearBrowserCache` dan server dihentikan, `/` tetap merender shell;
  rute tak dikenal menampilkan `offline.html` dengan tombol "Muat ulang".

### MEDIUM: Purpose-Gate

Tidak ada temuan baru. Permukaan PWA memakai teknik yang sudah ada di
`DESIGN.md`: biru solid, kartu putih, radius 12-16px, shadow tipis, dan ikon
yang relevan. Tidak ada gradient, glassmorphism, glow, badge kapsul, atau
ilustrasi baru.

### LOW: Consistency

Tidak ada temuan baru. Teks baru memakai 10-12px, sentence case, dan palet
slate/blue yang sama. Tidak ada em dash di teks UI baru.

## Yang sudah lolos

- **Manifest:** `Page.getInstallabilityErrors` kosong; `Page.getAppManifest`
  tanpa error; 4 ikon (192/512, any + maskable) dan 3 shortcut terbaca.
- **Ikon:** 192x192, 512x512, maskable 192/512, apple-touch 180x180. Semua
  diturunkan dari `src/app/icon.svg` yang sudah ada, bukan logo baru.
- **Service worker:** aktif di scope `http://localhost:3100/`; cache
  `campus-lost-found-v3`; header `/sw.js` no-cache.
- **Offline:** `/` tampil dari Cache Storage setelah server dimatikan dan cache
  HTTP dibersihkan; rute tak dikenal menampilkan `offline.html`; tombol
  "Muat ulang" benar-benar memuat ulang halaman.
- **Install card:** muncul saat `beforeinstallprompt` tersedia atau di iOS
  Safari; tombol pasang memicu prompt; tombol tutup menyimpan dismissal 14 hari;
  toast sukses/gagal/batal tersedia.
- **iOS:** dengan UA iPhone, kartu menampilkan instruksi Bagikan lalu Tambahkan
  ke Layar Utama, tanpa tombol pasang palsu; tombol tutup 44x44; tanpa overflow.
- **Mobile:** 320/375/768 tanpa overflow horizontal; kartu muat; tombol pasang
  118x44; tombol tutup 44x44.
- **Keyboard:** urutan Tab logis; tombol pasang dan tutup terlihat fokusnya;
  tombol tutup punya nama aksesibel.
- **Kontras:** semua pasangan baru PASS. Nilai terendah 4.75:1 (subtitle offline
  10px), 4.76:1 (slate-500 di putih), 5.17:1 (ring fokus biru di putih),
  6.16:1 (blue-700 di blue-50), 6.70:1 (putih di blue-700), 7.58:1
  (slate-600 di putih), 14.63:1 (slate-800 di putih), 17.85:1 (ring fokus
  offline).
- **Kebersihan:** tidak ada console error, tidak ada 404, tidak ada em dash di
  teks UI baru.
- **Build:** `next build` sukses (Next.js 16.4.3, 15/15 halaman);
  `tsc --noEmit` sukses.
- **R-24:** shortcut manifest menuju rute yang benar-benar ada: `/lapor`,
  `/pesan`, `/klaim`.
- **R-26:** tidak ada kontrol mati. Tombol pasang, tutup, dan muat ulang punya
  perilaku nyata. Varian iOS hanya berisi instruksi, bukan tombol palsu.

## Batasan audit (jujur)

- Dialog instalasi native tidak bisa diselesaikan di Edge headless. Event
  `beforeinstallprompt` nyata terpicu, `installabilityErrors` kosong, dan alur
  accepted/dismissed diuji dengan event tiruan. Dialog OS-nya sendiri tidak
  dapat diklik otomatis.
- Jalur iOS diverifikasi lewat emulasi UA dan inspeksi kode, bukan perangkat
  iOS fisik.
- PWA hanya aktif di build produksi. `next dev` tidak mendaftarkan service
  worker.
- Deploy produksi harus HTTPS (localhost dikecualikan) agar service worker dan
  prompt instalasi berjalan.
