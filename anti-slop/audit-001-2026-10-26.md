## Temuan (angka berjalan terus pada audit berikutnya)

### PRIORITAS TINGGI — Hard Gate (pelanggaran bersifat mutlak)

**#1 — R-25 Kontras warna: teks kecil abu-abu terang di atas putih gagal WCAG AA**
- `text-slate-400` (#94a3b8) di atas putih = ±2.9:1, di bawah 4.5:1, tetapi dipakai untuk teks nyata 9–11px:
  - `BerandaView.tsx` L330 (label item), `DetailView.tsx` L168/L174/L291 (label "LOKASI GEDUNG", "WAKTU LAPORAN", label tiket), `ChatInterface.tsx` L62/L86 (label, timestamp), `BottomNav.tsx` la semua: L67/L79/L93/L106/L118/L130 (label navigasi, tapi pasangan aktif biru aman — yang pasif gagal), `MyClaimsView.tsx` label kecil, `AccountSettingsView.tsx` L303/L314/L331/L348 + L31 (label bagian)
- Alasan: teks petunjuk/fungsional (label navigasi, jam pesan) bukan sekadar dekorasi, 9px + kontras gagal = tidak terbaca bagi penglihatan lemah.
- Galat minor serumpun: kamera overlay `text-white/50` (PhotoCapture L256) dan `text-white/60` (AccountSettingsView L203) di atas video.

**#2 — R-32 Aksesibilitas keyboard: overlay/modal tidak bisa ditutup dengan Escape**
- Tidak ada penanganan `Escape` di seluruh `src/` (grep 0 nilai):
  - `ChatInterface.tsx` (overlay percakapan)
  - `PhotoCapture.tsx` kamera layar ibu (overlay)
  - `LoginGateModal.tsx`
- Tombol X ✓, tetapi pengguna keyboard-only terjebak; R-32 mensyaratkan dialog tertutup Escape.

**#3 — R-27 UI states: state ERROR tidak tersedia pada gawai penghadap data**
- `AppContext.tsx` L211: `refreshData` berisi `Promise.all` tanpa `try/catch`. Bila pengambilan gagal (jaringan/RLS), `dataLoading` terjebak `true` → kerangka halaman indeks menampilkan skeleton **tanpa batas** tanpa pesan sama sekali.
- State kosong ✓ (Beranda, Klaim Saya, Pesan, Admin) dan pengirim (loading) ✓ skeleton — jadi hanya ERROR yang hilang; lalu gagal kirim ditangani lewal toast (bagus), tapi kegagalan MEMUAT tidak.

**#4 — R-02 Em dash (—) pada teks UI yang dilihat pengguna**
- `PhotoCapture.tsx` L200: `... KB) — format &amp; ukuran valid`
- `PhotoCapture.tsx` L220: `Kamera Belakang — arahkan ke objek, lalu jepret`
- `PesanView.tsx` L134: `...disetujui — setelah itu`
- `PesanView.tsx` L189: `Belum ada pesan — mulai chat`
- Aturan: ganti koma/titik salah satunya. (Enam temuan lain — berada di acak komentar kode, bukan teks UI, tidak diperlakukan di sini.)

### PRIORITAS SEDANG — Purpose-Gate (boleh dieksekusi dengan alasan yang jelas)

**#5 — R-04 Ikon AI generik `Sparkles` tanpa relevansi konten**
- `BerandaView.tsx` L123: tombol "Lapor Sekarang" diakhirinya ✨ Sparkles → ikon default-AI, tidak berhubungan dengan lapor barang.
- `LoginView.tsx` L50: kotak info arahan login memakai Sparkles (context-nya "akun kampus", bukan AI/magic).
- Boleh dipertahankan jika ditulis alasan makna; tanpa alasan → ganti ikon relevan (mis. `MapPinPlus`/`PackagePlus`) atau hapus.

**#6 — R-36 Klaim tanpa bukti: "Pesan Terenkripsi Aman"**
- `ChatInterface.tsx` L47: header chat kekal "Pesan Terenkripsi Aman". Chat terlindungi RLS + TLS, tapi frasa "terenkripsi" menuntut/menjanjikan enkripsi end-to-end yang TIDAK dimiliki. Klaim keamanan fiktif = Hard Gate R-36.
- Ganti frasa faktual: "Chat privat antarpeserta klaim" (dan sudah dipastikan RLSmengunci hanya peserta).

**#7 — R-01/R-13 Ornamen cahaya (glow) dekoratif tanpa ipteks di hero**
- `BerandaView.tsx` L127–128: dua lingkaran blur putih/biru transparan sebagai dekorasi hero. Dosis rendah (1 komposisi), tapi alasan (purpose) belum pernah tertulis. Catat alasan atau turunkan/tranparankan agar tidak dianggap tempelan.

**#8 — R-19 Animasi `animate-fadeIn` dipakai sebagai bypass default di 8 posisi**
- `BerandaView`/`DetailView`/`MyClaimsView` ×2/`PesanView`/`ChatInterface`/`LoginGateModal`. Satu guna gerak untuk semua konteks, tanpa perihal "(panduan) perhatian". Boleh dipasang setelah alasan satu kalimat per konteks, atau dihilangkan di potongan non-kritis.

### PRIORITAS RENDAH — Quality Locks

**#9 — R-06/R-31 Label UPPERCASE + tracking-widest adalah pola berulang tanpa dendang**
- Pola `text-[9px]/[10px] font-bold uppercase tracking-wider/widest` berulang di banyak label (Beranda L238/L330, ChatInterface L62/L86, item kartu, dll). Satu aksara hierarki, tetapi tanpa alasan tertulis; perlu 1 kalimat (mis. "mahasiswa sepintas baca cepat") atau diversifikasi tipis di bagian Ritme.

**#10 — R-06 Typeface default tanpa alasan tertulis** (data di `globals.css`: stack generik/Inter-family)
- Dilarang saat memilih default tanpa alasan — tidak kena Hard Gate (Inter boleh jika ada alasan). Tambahkan kalimat alasan di `DESIGN.md`, atau `DESIGN.md` belum ada — lihat Catatan Arah di bawah.
